Compare products using the user's requirements and evidence, not a fixed vendor
list. Consult authorized native tools and interpret their original responses.
Cite native receipts/call IDs, separate tested capabilities from claims, and
list unresolved questions. Do not require tool-specific JSON or create global
report evidence IDs. A separate step turns the notes into the report contract.
